# Christmas Tree · v17.6

一个纯静态的交互式圣诞树页面：旋转的螺旋彩灯圣诞树、飘雪、星芒，支持上传照片做树上挂饰、上传本地音乐、摄像头动作互动。

## 预览

打开 `index.html`，或访问 GitHub Pages 部署地址。

## 功能

- 🎄 Canvas 粒子圣诞树，手机/桌面自适应（DPR 高清、安全区适配）
- ⏸ 暂停 / 继续动画
- 🔔 音乐开关：默认播放 Web Audio 合成的八音盒版《铃儿响叮当》
- 🎵 上传本地音乐：选择 mp3 / wav / m4a 等音频，循环播放，替换默认合成音乐
- 🖼 上传照片：照片变成金色相框挂到树上，最多 12 张，随树一起旋转、有前后遮挡
- 📷 摄像头互动：开启前置摄像头后，画面在左上角小窗显示；对着镜头挥动手臂/身体，树上彩灯会变亮、雪花加速飘落
- 尊重系统「减少动态效果」设置

## 关于隐私

照片与音乐都在浏览器本地读取后直接渲染/播放，**不会上传到任何服务器**；关闭或刷新页面后需要重新选择文件。

## 本地运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

摄像头需要 `https://` 或 `localhost` 才能授权；GitHub Pages 默认就是 HTTPS。

## 部署

仓库 Settings → Pages → Source 选择 `main` 分支根目录（已开启）。
